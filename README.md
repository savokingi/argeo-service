# ARGEO Service

Сайт: https://savokingi.github.io/argeo-service/

Репозиторий: https://github.com/savokingi/argeo-service

Авторский адаптивный сайт мастерской по ремонту техники в Ульяновске. HTML, CSS и JavaScript с объёмной моделью на Three.js. Библиотека и шрифты размещаются локально. В контактах встроен интерактивный виджет Яндекс Карт.

## Локальный запуск

Нужен Node.js 20 или новее. Перед первым запуском выполните `npm ci`.

```sh
npm run dev
```

Открыть http://127.0.0.1:4173/.

## Проверка и сборка

```sh
npm run check
npm run build
```

Готовые файлы находятся в `dist/`. Все пути относительные; сайт работает и в корне домена, и в подпапке репозитория GitHub Pages.

## Публикация на GitHub Pages

В проект включён workflow `.github/workflows/pages.yml`.

1. Разместить проект в выбранном GitHub-репозитории в ветке `main`.
2. В настройках репозитория открыть Settings → Pages → Source → GitHub Actions.
3. Отправить изменения в `main` или запустить workflow вручную.

Workflow проверяет JavaScript, собирает `dist/` и публикует его в GitHub Pages. Новые изменения в `main` автоматически запускают публикацию.

## Что работает

- Объёмная модель смартфона: корпус, дисплей, аккумулятор, системная плата, камеры, разъёмы. Плавная разборка и обратная сборка по общей оси.
- Каталог с подробностями пяти направлений в диалогах.
- Выбор устройства и неисправности с контекстными пояснениями.
- Подготовка обращения, предпросмотр, копирование и переход в Telegram.
- Мобильное меню, закреплённые действия, карусель отзывов и раскрывающиеся вопросы.
- Телефонные ссылки, ВКонтакте, Telegram, интерактивная Яндекс Карта с организацией и отдельная ссылка построения маршрута.
- Управление с клавиатуры, возврат фокуса после диалогов и поддержка reduced motion.
- Локальные шрифты, метаданные и структурированные данные LocalBusiness.

## Обновление материалов

Тексты и контакты — `index.html`. Направления услуг и подсказки — `app.js`, объекты `serviceData` и `symptoms`. Оформление и адаптивные состояния — `styles.css`. Модель и её анимация — `phone-scene.js`; `scripts/bundle.mjs` собирает локальный JS-модуль при запуске и сборке.

Форма не передаёт заявки на сервер и не отправляет сообщения автоматически: посетитель копирует подготовленный текст и отправляет его в Telegram самостоятельно.

Реальный прайс, фотографии команды и документированные кейсы не были предоставлены. Выдуманные цены, мастера, кейсы и показатели на сайте не используются. Объёмный смартфон и графика платы — авторские иллюстрации. Карта загружается из Яндекс Карт; для виджета требуется интернет. При отсутствии WebGL используется статичная иллюстрация смартфона. Анимация останавливается, когда модель вне экрана или вкладка скрыта.

Перед публикацией владельцу сервиса следует сверить перечень работ, правила диагностики, конкретные условия гарантии и действительность акции. На сайте уже указано, что эти условия уточняются при обращении.

Источники и лицензия шрифта — в `SOURCES.md` и `assets/FONT-LICENSE.txt`.
